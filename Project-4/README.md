# OracleGenAI-RAG: Enterprise Knowledge Assistant via OCI Generative AI

[![OCI Generative AI](https://img.shields.io/badge/OCI-Generative%20AI-purple.svg)](https://www.oracle.com/artificial-intelligence/generative-ai/)
[![Oracle Database](https://img.shields.io/badge/Oracle-Autonomous%20DB-blue.svg)](https://www.oracle.com/database/autonomous-database/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

An enterprise knowledge assistant leveraging **OCI Generative AI Service (Cohere Command R+ / Llama 3)** via Python OCI SDK, storing conversation histories in **Oracle Autonomous Database**.

---

## Features
- 🤖 **OCI Generative AI Integration:** Fully managed foundation model inference via `oci.generative_ai_inference` SDK.
- 💾 **Oracle Autonomous DB Audit Trail:** Persists prompt/response records and latencies.
- 💻 **Next.js 14 Web Interface:** Modern, responsive assistant UI.
