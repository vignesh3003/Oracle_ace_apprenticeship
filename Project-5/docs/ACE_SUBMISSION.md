# Oracle ACE Apprentice Contribution Document

# Contribution Title
**OCI MediaStream-AI: Multimodal Video & Audio Transcriber using OCI Speech AI Service**

# Project Overview
OCI MediaStream-AI is an automated media processing pipeline that ingests audio/video files into OCI Object Storage, triggers OCI Speech AI Service for automatic speech-to-text transcription, and indexes transcripts in Oracle Autonomous Database.

# Oracle Technologies Used
1. **OCI Speech AI Service:** Transcription API via `oci.ai_speech` SDK.
2. **OCI Object Storage:** Media storage bucket `mediastream-bucket`.
3. **Oracle Autonomous Database:** Database for storing transcript audit logs.
