# Oracle ACE Apprentice Contribution Document

# Contribution Title
**OracleCloudGuard-X: Automated Infrastructure Security Compliance Auditor on OCI Vault**

# Project Overview
OracleCloudGuard-X is an automated security compliance auditing tool that scans OCI resource configurations via OCI Python SDK, verifies AES-256 secret encryption inside OCI Vault (KMS), and records compliance audit logs in Oracle Autonomous Database.

# Oracle Technologies Used
1. **OCI Vault (Key Management Service - KMS):** Secret encryption & KMS API via `oci.key_management`.
2. **OCI Notification Service (ONS):** Real-time security alert topic notifications.
3. **Oracle Autonomous Database:** Audit telemetry database.
